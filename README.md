## Steps to Run

1. Install frontend deps and run app
```bash
npm i
npm start
```
2. Install backend deps and run api
- Setup the env variables and run
```bash
python3 -m venv .venv
source .venv/bin/activate
pip3 install -r requirements.txt
python3 api.py
```
3. Access
- Access the application on localhost:3000
- Access the api on localhost:8000
